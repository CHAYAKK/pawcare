# 🐾 PawCare

## Pet Care & Wellness Website

PawCare is a modern, responsive pet care website designed
to provide pet owners with useful information, services
and resources for better pet care.

---

## ✨ Features

- Modern premium UI
- Responsive design
- Home page
- About page
- Services page
- Pet care tips
- Pet gallery
- Gallery filtering
- Contact form
- Form validation
- Dark/light theme
- Animated statistics
- Scroll animations
- Mobile navigation
- Back-to-top button

## 🚀 How to Run

### Method 1 - Live Server

1. Open the project in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Select "Open with Live Server".

### Method 2 - Browser

Open `index.html` directly in a browser.
