# PawCare - API Documentation

## Current API Status

PawCare is currently a frontend-only application.

No backend APIs are implemented in the current version.

## Future APIs

The following APIs may be implemented in a future version.

### POST /api/contact

Purpose:

Submit a contact form.

Example request:

{
    "name": "John",
    "email": "john@example.com",
    "subject": "Pet Care",
    "message": "I need information."
}

### GET /api/services

Purpose:

Retrieve available pet care services.

### GET /api/tips

Purpose:

Retrieve pet care tips.

### POST /api/appointments

Purpose:

Create a pet care appointment.

## Authentication

No authentication is currently required.
